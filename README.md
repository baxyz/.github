| Path | Purpose |
| --- | --- |
| `CONTRIBUTING.md` | Contribution guidelines (all repos) |
| `CODE_OF_CONDUCT.md` | Code of conduct |

| `PULL_REQUEST_TEMPLATE.md` | Default PR template |

| `.github/dependabot.yml` | Automated dependency updates |
